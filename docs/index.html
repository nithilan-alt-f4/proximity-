Windows 10 / 11 (64-bit) — installer or portable single-file, no admin needed.

macOS

Pick your Mac type — Apple Silicon (M1/M2/M3/M4) or Intel.

↓ Apple Silicon ↓ Intel

No sign-up, no API keys needed — everything is baked in. Installers are unsigned; Windows may show a blue "Windows protected your PC" screen — click More info → Run anyway, and macOS users: right-click → Open the first time.

Your music files never leave your machine. Only filenames are sent for AI identification.
